# 陳秀麗嶺南彩墨作品集

收錄50幅作品。純靜態網站，無須安裝或建置。首頁為 index.html。

## 上傳 GitHub Pages

1. 在 https://github.com/new 建立公開儲存庫，例如 chen-hsiu-li-gallery。
2. 將此資料夾內全部內容（不是外層資料夾）上傳至儲存庫根目錄。確認首頁 index.html 與 assets 資料夾位於同一層。
3. 在儲存庫 Settings → Pages → Build and deployment 選 Deploy from a branch。
4. 選 main、/(root)，按 Save。
5. 等候 GitHub 顯示網站連結。網址通常為 https://你的帳號.github.io/chen-hsiu-li-gallery/。

## 照片與文稿

- assets 保存原照片，網頁依 data.js 的個別 brightness 參數調整顯示亮度，並可切回原照與微調亮度。這些是顯示修正，沒有改寫原照片像素。
- 橫置荷花照片在網頁轉正。
- 55張照片移除4張完全相同副本，以及1張同畫另照，共收錄50幅。詳細見作品整理.md。
- 除可辨識的題名外，名稱為編輯擬題。理念是依畫面撰寫的詮釋，非畫家自述。網站已清楚標示。
- 畫家簡介依提供資料：清朝秀才王作霖之外孫女，師承黃磊生。
- 修改 data.js 可調整作品名稱、分類、文稿及顯示亮度。
- 無外部字型、追蹤或網路資源；手機支援分類、搜尋、放大，桌面支援方向鍵及全螢幕。
